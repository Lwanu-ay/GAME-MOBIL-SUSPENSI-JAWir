# 🚗 [GAME MOBIL SUSPENSI TINGGI ALA-ALA JAWIR] — Hill Climb Racing Sederhana

Game balap mobil bergaya *hill climb* yang dibangun dengan **HTML5 & JavaScript**, langsung jalan di browser tanpa perlu install apa-apa.

## ✨ Fitur

- Fisika mobil sederhana menyusuri medan berbukit
- Kontrol keyboard **dan** touch/tap di layar — bisa dimainkan di desktop maupun HP
- Ringan dan cepat dimuat, tanpa dependensi berat
- 100% berjalan di browser (client-side)

## 🕹️ Cara Main

**Keyboard**

| Tombol | Aksi |
| --- | --- |
| `→ / D` | Gas / maju |
| `← / A` | Rem / mundur |


**Touch (mobile)**

- Tap tombol gas pool di layar untuk maju
- Tap tombol ngerem di layar untuk mundur/rem

## 🛠️ Teknologi

- HTML5 (`<canvas>`)
- JavaScript (vanilla, tanpa framework) <!-- sebutkan library kalau pakai, mis. Matter.js untuk fisika -->
- CSS untuk tampilan UI

## 🚀 Menjalankan di Lokal

Karena ini murni HTML/JS, cukup buka langsung filenya:

```bash
git clone https://github.com/username/nama-repo.git
cd nama-repo
```

Lalu buka `index.html` di browser, atau jalankan server lokal sederhana:

```bash
# pakai Python
python3 -m http.server 8000

# atau pakai Node (npx serve)
npx serve .
```

Buka `http://localhost:8000` di browser.
